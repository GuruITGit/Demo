# Smart SAO — สอนวิธีใช้งานระบบ (สคริปต์สไลด์ Canva)

---

## สไลด์ 1: หน้าปก

- **Smart SAO — คู่มือการใช้งานระบบ**
- โลโก้/ตราหน่วยงาน

---

## สไลด์ 2: การเข้าเว็บ

1. เปิดเบราว์เซอร์ Chrome / Edge / Safari (คอมหรือมือถือก็ได้)
2. พิมพ์ที่อยู่เว็บ: **[https://203.154.140.209/login]**
3. กด Enter
4. แนะนำ: บันทึกเป็น Bookmark หรือ "เพิ่มไปยังหน้าจอโฮม" บนมือถือ ครั้งหน้ากดเข้าได้เลย

**ภาพ:** ช่อง address bar พิมพ์ URL + ลูกศรชี้

---

## สไลด์ 3: เข้าสู่ระบบ

1. กรอก **ชื่อผู้ใช้** (ได้รับจากผู้ดูแลระบบ)
2. กรอก **รหัสผ่าน**
3. กดปุ่ม **"เข้าสู่ระบบ"**

⚠️ ห้ามบอกรหัสผ่านคนอื่น — ทุกการกระทำในระบบบันทึกเป็นชื่อเรา

**ภาพ:** หน้า Login วงกลมช่องกรอก + ปุ่ม

---

## สไลด์ 4: เข้าครั้งแรก — เปลี่ยนรหัสผ่าน

1. กดรูปโปรไฟล์ **มุมขวาบน** → เลือก **"โปรไฟล์"**
2. ไปที่กล่อง **"เปลี่ยนรหัสผ่าน"**
3. กรอกรหัสผ่านเดิม → รหัสผ่านใหม่ (อย่างน้อย 8 ตัว) → ยืนยันรหัสผ่านใหม่
4. กดปุ่ม **"เปลี่ยนรหัสผ่าน"**

**ภาพ:** หน้าโปรไฟล์ วงกลมกล่องเปลี่ยนรหัสผ่าน

---

## สไลด์ 5: เข้าครั้งแรก — ตรวจข้อมูล + ใส่รูปโปรไฟล์

1. ในหน้าโปรไฟล์ ตรวจ **คำนำหน้า / ชื่อ-สกุล / เบอร์โทร** ให้ถูกต้อง → กด **"บันทึก"**
2. ใส่รูปโปรไฟล์: กดที่ **วงกลมรูปตัวเอง** → เลือกรูปจากเครื่อง → ระบบบันทึกให้อัตโนมัติ

**ภาพ:** หน้าโปรไฟล์ วงกลมจุดกดเปลี่ยนรูป

---

## สไลด์ 6: เข้าครั้งแรก — บันทึกลายเซ็น

1. เมนูซ้าย → **"จัดการลายเซ็น"**
2. กดปุ่ม **"เพิ่มลายเซ็น"**
3. เลือกได้ 2 วิธี:
   - **วาดสด** — ใช้นิ้ว (มือถือ) หรือเมาส์วาดลายเซ็นในกรอบ
   - **อัปโหลดรูป** — ถ่ายรูปลายเซ็นบนกระดาษขาวมาอัปโหลด
4. กด **"บันทึก"**
5. อยากเปลี่ยน/ลบ กลับมาที่หน้านี้ได้ตลอด (ปุ่ม "เปลี่ยน" / "ลบ")

💡 ลายเซ็นนี้จะถูกเรียกใช้ตอนเซ็นอนุมัติเอกสาร ไม่ต้องวาดใหม่ทุกครั้ง

**ภาพ:** หน้าจัดการลายเซ็น + หน้าต่างวาดลายเซ็น

---

## สไลด์ 7: รู้จักหน้าจอหลัก

- **แถบบน:** ชื่อหน่วยงาน · 🔔 กระดิ่งแจ้งเตือน · รูปโปรไฟล์ (กดเพื่อไปหน้าโปรไฟล์/ออกจากระบบ)
- **เมนูซ้าย:** ทางเข้าโมดูลทั้งหมด — แต่ละคนเห็นไม่เท่ากันตามสิทธิ์
- **กลางจอ:** เนื้อหาของหน้าที่เปิดอยู่
- **บนมือถือ:** เมนูซ่อนอยู่ กดปุ่ม **☰ มุมซ้ายบน** เพื่อเปิด

**ภาพ:** หน้า Dashboard เต็มจอ ตีกรอบ 3 โซน + ภาพมือถือกด ☰

---

## สไลด์ 8: การแจ้งเตือน 🔔

1. มีเรื่องใหม่ถึงเรา → กระดิ่งขึ้น **ตัวเลขแดง**
2. กดกระดิ่ง → ป๊อปอัปแสดงรายการแจ้งเตือน
3. กดที่รายการ → ระบบพาไปหน้าเรื่องนั้นทันที

💡 เปิดเช็กกระดิ่งทุกเช้า จะไม่พลาดงานที่ส่งมาถึงเรา

**ภาพ:** กระดิ่งมีเลขแดง + ป๊อปอัปแจ้งเตือน

---

## สไลด์ 9: เมนูทั้งหมดในระบบ

| กลุ่ม | เมนู | ใช้ทำอะไร |
|---|---|---|
| งานสำนักงาน | 📬 สารบรรณ | รับ-ส่งหนังสือ เสนอเซ็น ติดตามเรื่อง |
| งานสำนักงาน | 📁 คลังเอกสาร | เก็บ/ค้นหาไฟล์กลางของหน่วยงาน |
| งานสำนักงาน | 📅 การประชุม | นัดประชุม วาระ เชิญผู้เข้าร่วม |
| งานสำนักงาน | 📊 รายงานสรุปประจำเดือน | สรุปสารบรรณรายปี/เดือน กราฟ + รายการ (ปุ่มบนหน้าหลัก เฉพาะผู้มีสิทธิ์) |
| งานสำนักงาน | ✍️ จัดการลายเซ็น | บันทึกลายเซ็น + ดูประวัติการลงนาม |
| บุคลากร | 👥 บุคลากร | ทำเนียบเจ้าหน้าที่ ตำแหน่ง เบอร์ติดต่อ |
| บุคลากร | 🗓️ การลา | ยื่นใบลา ดูโควตา อนุมัติการลา |
| โครงการ | 📋 โครงการ | เขียน/เสนอโครงการตามแบบฟอร์มราชการ |

---

## สไลด์ 10: สารบรรณ — สร้างเรื่องใหม่ (รับหนังสือเข้า)

1. เมนูซ้าย → **"สารบรรณ"** → กดปุ่ม **"สร้างเรื่องใหม่"**
2. กรอกข้อมูลตามหัวหนังสือจริง:
   - เลขที่เอกสาร / ลงวันที่ / จาก / เรื่อง / เรียน
   - ความเร่งด่วน (ปกติ/ด่วน/ด่วนมาก/ด่วนที่สุด)
   - ชั้นความลับ (ถ้ามี)
   - กองเจ้าของเรื่อง + ผู้รับผิดชอบ
3. แนบไฟล์/รูปหนังสือ (กดปุ่มแนบไฟล์ หรือลากไฟล์มาวาง)
4. กด **"บันทึก"** → ระบบออก **เลขทะเบียนรับอัตโนมัติ** และส่งเรื่องไปที่กองทันที

💡 ระบบบันทึก **"ผู้สร้างสารบรรณ"** จากบัญชีที่ล็อกอินให้เอง (ไม่มีช่องกรอก กันแอบอ้าง) — แสดงในรายการ/รายละเอียด/รายงานสรุป

**ภาพ:** ฟอร์มสร้างเรื่อง วงกลมช่องสำคัญ + ปุ่มบันทึก

---

## สไลด์ 11: สารบรรณ — ติดตามเรื่อง

1. หน้ารายการสารบรรณ เห็นทุกเรื่องของกองเรา พร้อม **สถานะสี**:
   - 🟡 รอดำเนินการ · 🔵 กำลังดำเนินการ · 🟣 รอปลัด · 🟠 รอนายก · 🟢 เสร็จสิ้น
2. ใช้ช่อง **ค้นหา** — พิมพ์เลขหนังสือหรือชื่อเรื่อง
3. กดที่เรื่อง → เห็นรายละเอียดครบ + **ไทม์ไลน์** ว่าใครทำอะไรเมื่อไหร่

**ภาพ:** รายการเรื่อง + หน้ารายละเอียดที่เห็นไทม์ไลน์

---

## สไลด์ 12: สารบรรณ — ดำเนินการ + ส่งขึ้นผู้บริหาร (เจ้าหน้าที่กอง)

1. เปิดเรื่องที่ได้รับมอบหมาย → กด **"รับเรื่อง/ดำเนินการ"** (สถานะเปลี่ยนเป็น "กำลังดำเนินการ")
2. ทำงานตามเรื่อง แนบไฟล์ผลงาน/เอกสารเพิ่มได้
3. เสร็จแล้วกด **"เสนอปลัด"** → เรื่องวิ่งขึ้นไปรอปลัดตรวจ

**ภาพ:** หน้าเรื่อง วงกลมปุ่มดำเนินการ/เสนอ

---

## สไลด์ 13: สารบรรณ — เซ็นอนุมัติ (ปลัด / นายก)

1. เปิดเรื่องที่รออนุมัติ (ดูจากกระดิ่ง หรือหน้ารายการกรองสถานะ "รอปลัด"/"รอนายก")
2. อ่านรายละเอียด + ไฟล์แนบ
3. กดปุ่ม **"อนุมัติ/ลงนาม"**
4. เลือกลายเซ็น:
   - ใช้ **ลายเซ็นที่บันทึกไว้** (กดเลือกได้เลย)
   - หรือ **วาดสด** ตอนนั้น
5. กด **"ยืนยัน"** — ระบบบันทึกลายเซ็น + เวลา + ชื่อผู้เซ็นอัตโนมัติ

**ภาพ:** หน้าต่างเลือกลายเซ็นตอนอนุมัติ

---

## สไลด์ 14: สารบรรณ — กรณีตีกลับ

**ฝั่งผู้บริหาร (ปลัด/นายก):**
1. ไม่เห็นชอบ → กด **"ส่งกลับแก้ไข"**
2. พิมพ์เหตุผล → ยืนยัน

**ฝั่งกองเจ้าของเรื่อง:**
1. ได้รับแจ้งเตือน 🔔 → เปิดเรื่อง อ่านเหตุผลในไทม์ไลน์
2. แก้ไข/แนบเอกสารใหม่ในเรื่องเดิม
3. กด **"ส่งใหม่"**

💡 ถ้านายกเป็นคนตีกลับ ส่งใหม่แล้วเรื่องวิ่งตรงไปนายกเลย ไม่ผ่านปลัดซ้ำ

**ภาพ:** ไทม์ไลน์ที่มีรายการ "ส่งกลับแก้ไข" + เหตุผล

---

## สไลด์ 15: ภาพรวมเส้นทางหนังสือ (Workflow)

```
📥 รอดำเนินการ → 🔄 กำลังดำเนินการ → 👤 รอปลัด → 👑 รอนายก → ✅ เสร็จสิ้น
  (ธุรการรับเรื่อง)   (กองทำงาน)      (ปลัดเห็นชอบ)  (นายกอนุมัติ)
```

- ทุกขั้นมีบันทึกเวลา + ชื่อผู้ทำ ย้อนดูได้ตลอด
- ตีกลับได้ทุกขั้นตรวจ → กลับไปที่กอง → แก้แล้วส่งใหม่ในเรื่องเดิม

**ภาพ:** แผนภาพ 5 กล่องลูกศร ใช้สีตามสถานะจริง + ลูกศรย้อนกลับสีส้ม

---

## สไลด์ 15.1: รายงานสรุปประจำเดือน (Summarize Report) — การเข้าใช้

> สำหรับผู้บริหาร/หัวหน้า — สรุปสารบรรณทั้งเดือนในหน้าเดียว ไม่ต้องนับมือ

1. กดปุ่มใหญ่ **"รายงานสรุปประจำเดือน"** บนหน้าหลัก (เห็นเฉพาะผู้ได้รับสิทธิ์: นายก/ปลัด/หัวหน้ากอง หรือผู้ที่แอดมินเปิดให้)
2. เลือก **ปี พ.ศ.** — การ์ดแต่ละปีบอกจำนวนเรื่องรวม
3. เลือก **เดือน** — ตาราง 12 เดือนพร้อมจำนวน เดือนไม่มีข้อมูลกดไม่ได้

🔒 ตัวเลขและรายการแสดงเฉพาะเรื่องที่ผู้ดูมีสิทธิ์เห็น (กองตน + ชั้นความลับ) เหมือนหน้าสารบรรณปกติ

**ภาพ:** หน้าเลือกปี + หน้าเลือกเดือน

---

## สไลด์ 15.2: รายงานสรุปประจำเดือน — หน้าสรุปของเดือน

- **การ์ดตัวเลขรวม** ด้านบน: ทั้งหมด • หนังสือรับ • หนังสือส่ง • เสร็จสิ้น • ระหว่างดำเนินการ
- **กราฟ** แยกตามหมวดหมู่หนังสือ และแยกตามกอง — เห็นทันทีว่างานหนักที่ไหน
- **แถบสัดส่วน** สถานะ / ความเร่งด่วน / สมุดทะเบียน
- ล่างสุด: **ตารางรายละเอียดสารบรรณทุกเรื่องของเดือน** (พร้อมผู้สร้างสารบรรณ) กดเปิดดูฉบับเต็มได้

**ภาพ:** หน้าสรุปเดือน (การ์ด+กราฟ) + ตารางรายการเรื่อง

---

## สไลด์ 16: การลา — บันทึกเข้าระบบ มีผลทันที

> แนวคิด: ตกลงกับหัวหน้าตามปกติ (โทร/ไลน์) แล้วมาบันทึกในระบบให้ทุกคนเห็นสถานะ — **ไม่มีขั้นรออนุมัติ**

1. เมนูซ้าย → **"การลา"** → กดปุ่มบันทึกการลา
2. เลือกประเภท: ลาป่วย / ลากิจ / ลาพักผ่อน
3. เลือกวันที่เริ่ม–สิ้นสุด (ระบบนับวันทำการให้) + พิมพ์เหตุผล + ผู้ปฏิบัติหน้าที่แทน
4. กดส่ง → **มีผลทันที** หัวหน้าได้รับแจ้งเตือนเพื่อทราบ และสถานะ "ลา" ขึ้นในทำเนียบบุคลากรอัตโนมัติ

**ภาพ:** หน้ารายการการลา + ฟอร์มบันทึกการลา

---

## สไลด์ 17: การประชุม

**สร้างนัดประชุม:**
1. เมนูซ้าย → **"การประชุม"** → กด **"สร้างการประชุม"**
2. กรอกหัวข้อ วันเวลา สถานที่ + เพิ่ม **วาระการประชุม**
3. เลือก **ผู้เข้าร่วม** → แนบเอกสารประกอบ → บันทึก

**ผู้ถูกเชิญ:**
- เห็นนัดในระบบ + ได้รับแจ้งเตือน
- กดเข้าไปดูวาระและเอกสารประกอบได้ก่อนประชุม

**ภาพ:** ฟอร์มสร้างประชุม + หน้ารายละเอียดนัด

---

## สไลด์ 18: คลังเอกสาร

**อัปโหลดไฟล์:**
1. เมนูซ้าย → **"คลังเอกสาร"** → กด **"อัปโหลด"**
2. เลือกไฟล์ + ระบุหมวดหมู่ → บันทึก

**ค้นหาไฟล์:**
- พิมพ์ชื่อไฟล์/คำที่เกี่ยวในช่องค้นหา หรือกดกรองตามหมวด
- กดที่ไฟล์เพื่อเปิดดู หรือดาวน์โหลด

**ภาพ:** หน้าคลังเอกสาร วงกลมปุ่มอัปโหลด + ช่องค้นหา

---

## สไลด์ 19: บุคลากร + โครงการ

**บุคลากร:**
- เปิดดูทำเนียบเจ้าหน้าที่ทั้งหน่วยงาน — ตำแหน่ง กอง เบอร์ติดต่อ
- ใครกำลังลา ระบบแสดงสถานะให้เห็น

**โครงการ:**
1. เมนูซ้าย → **"โครงการ"** → กด **"สร้างโครงการ"**
2. กรอกแบบฟอร์ม 10 หัวข้อ (หลักการเหตุผล วัตถุประสงค์ งบประมาณ ฯลฯ)
3. แก้ไขภายหลังได้ — ระบบเก็บทุกเวอร์ชัน เทียบได้ว่าแก้ตรงไหน
4. แนบรูปกิจกรรม ก่อน/ระหว่าง/หลังดำเนินการ

**ภาพ:** ทำเนียบบุคลากร + ฟอร์มโครงการ

## สไลด์ 20: ปรับหน้าจอให้เหมาะกับตัวเอง

1. กดปุ่ม **ธีม** (ไอคอนที่แถบบน)
2. ปรับได้:
   - **สีธีม** ของระบบ
   - **ฟอนต์** และ **ขนาดตัวอักษร** (อ่านตัวเล็กไม่ถนัด → ขยายได้)
   - **โหมดมืด** สำหรับใช้งานกลางคืน
3. ระบบจำค่าที่ตั้งไว้ให้ เข้าครั้งหน้าไม่ต้องตั้งใหม่

**ภาพ:** ป๊อปอัปตั้งค่าธีม

## สไลด์ 21: ใช้งานบนมือถือ

1. เปิดเว็บเดียวกันจากเบราว์เซอร์มือถือได้เลย — ใช้ได้ทุกฟังก์ชัน
2. เมนู: กดปุ่ม **☰ มุมซ้ายบน**
3. เพิ่มไอคอนไว้หน้าจอ:
   - **iPhone (Safari):** ปุ่มแชร์ → "เพิ่มลงในหน้าจอโฮม"
   - **Android (Chrome):** ปุ่ม ⋮ → "เพิ่มลงในหน้าจอหลัก"
4. เหมาะกับผู้บริหาร — กดเซ็นอนุมัติจากมือถือได้ทุกที่

**ภาพ:** มือถือเปิดระบบ + ขั้นตอนเพิ่มไอคอน
