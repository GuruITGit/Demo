# เข้าเซิร์ฟเวอร์ INET ไม่ได้ตามเอกสารเดิม — บันทึกการไล่หาทาง (29 ก.ย. 2569)

> ⚠️ ไฟล์นี้เป็นบันทึกระหว่างไล่ปัญหา **ยังไม่ใช่ขั้นตอนที่ยืนยันแล้ว** ห้ามทำตามเป๊ะๆ จนกว่าจะพิสูจน์ครบ
> พอหาทางเข้าเซิร์ฟเวอร์จริงสำเร็จและยืนยันครบแล้ว ให้ย้ายสรุปที่ถูกต้องไปเขียนไว้ใน `HANDOVER.md` หัวข้อ "6. Deploy ขึ้นเครื่องจริง (INET)" แทน แล้วลบไฟล์นี้ทิ้งได้

## ปัญหาที่เจอ

`HANDOVER.md` เขียนไว้ว่า:
> เข้าเครื่อง: ssh ไปที่เซิร์ฟเวอร์ INET (ผู้ใช้ `GURU-IT`) โปรเจกต์อยู่ที่ `~/smartgov`

แต่ตอนนี้**ไม่มีข้อมูลให้ ssh ตรงจากเครื่องส่วนตัวได้เลย** (ไม่รู้ IP/โดเมน, ไม่มี user/รหัสผ่านสำหรับ ssh ตรง) สิ่งที่มีอยู่จริงคือ **รหัส AnyDesk** เท่านั้น ซึ่งเป็นคนละวิธีเข้าเครื่องจากที่เอกสารบอกไว้

## สิ่งที่ตรวจสอบแล้ว (ยืนยันจริง)

- เข้า AnyDesk ด้วยรหัสที่ได้มา → **เจอเครื่อง Windows** (พรอมต์ `C:\Users\OEM>`)
- เอกสาร `HANDOVER.md`/`docs/SELFHOST-UBUNTU.md` เขียนว่าเซิร์ฟเวอร์ INET ตัวจริงเป็น **Ubuntu + Docker Compose** — ไม่ตรงกับเครื่อง Windows ที่เจอ
- เครื่อง Windows นี้มีโฟลเดอร์ `C:\Users\OEM\.ssh\` อยู่ ข้างในมี:
  - `id_ed25519` (กุญแจลับ — **ห้ามเปิด/ห้าม copy เนื้อหาออกมาที่ไหนทั้งนั้น**)
  - `id_ed25519.pub` (กุญแจสาธารณะ เปิดดูได้ปลอดภัย)
  - `known_hosts`, `known_hosts.old`
  - **ไม่มีไฟล์ `config`** (เลยไม่มี alias/hostname ที่ตั้งไว้ล่วงหน้าให้ดู)

## ข้อสรุปที่น่าจะเป็น (ยังไม่ยืนยัน)

เครื่อง Windows (`OEM`) นี้น่าจะเป็น **jump host** — คือเครื่องกลางที่ต้องเข้ามาก่อน แล้วค่อย `ssh` ต่อออกไปเซิร์ฟเวอร์ Ubuntu ตัวจริงอีกที ไม่ใช่ตัวเซิร์ฟเวอร์ที่รันเว็บเอง

## สิ่งที่ยังไม่รู้ / ต้องหาต่อ

- [ ] IP หรือโดเมนของเซิร์ฟเวอร์ INET ตัวจริง (เซิร์ฟเวอร์ Ubuntu ที่รัน `docker compose`)
- [ ] เนื้อหาไฟล์ `known_hosts` (ค้างไว้ — ยังไม่ได้ดู อาจมีที่อยู่เซิร์ฟเวอร์ที่เคยต่อไว้ก่อนหน้า): `type "C:\Users\OEM\.ssh\known_hosts"`
- [ ] `id_ed25519` ที่เครื่อง jump host นี้ใช้ ssh ไปเซิร์ฟเวอร์ INET ได้จริงไหม (ยังไม่ได้ลอง `ssh GURU-IT@<host>`)
- [ ] ถามผู้ดูแลเดิม/คนที่ให้รหัส AnyDesk มา ว่าที่อยู่เซิร์ฟเวอร์ตัวจริงคืออะไร เผื่อไม่ต้องไล่หาเอง

## แผนต่อไป

1. เปิดดู `known_hosts` เพื่อหา host ที่เคยต่อไว้
2. ลอง `ssh GURU-IT@<host ที่เจอ>` จากเครื่อง jump host นี้
3. ถ้าเข้าได้ ยืนยันว่าเจอ `~/smartgov` จริงตามที่ `HANDOVER.md` บอกไว้
4. เขียนสรุปเส้นทางที่ถูกต้อง (AnyDesk → jump host Windows → ssh → เซิร์ฟเวอร์ Ubuntu) กลับไปแทนที่ส่วน "เข้าเครื่อง" ใน `HANDOVER.md` แล้วลบไฟล์นี้ทิ้ง
