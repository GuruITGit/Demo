# 🧾 คู่มือ: ตั้งค่า "ตรวจสลิปอัตโนมัติ" (กันสลิปปลอม/กันโกง)

> สำหรับ **เจ้าหน้าที่ อบต.** และ **ผู้ดูแลระบบ** — ตั้งครั้งเดียวต่อ อบต. แล้วใช้ได้ตลอด
> อัปเดต: 11 กันยายน 2569

---

## 1. ระบบนี้ช่วยอะไร

เดิมตอนรับเงินค่าน้ำแบบโอน/QR เจ้าหน้าที่กด **"ยืนยันรับเงิน"** ได้เลยโดยไม่มีหลักฐานว่าลูกค้าโอนเข้าจริง → **เสี่ยงโกงกัน** (กดรับทั้งที่ยังไม่มีเงินเข้า)

เปิด "ตรวจสลิปอัตโนมัติ" แล้ว ระบบจะบังคับว่า:

1. ลูกค้าสแกน QR จ่ายก่อน
2. เจ้าหน้าที่ **ถ่าย/แนบรูปสลิป** ที่ลูกค้าโอน
3. ระบบส่งสลิปไปตรวจกับธนาคารจริง — เช็ก **สลิปจริงไหม + ยอดตรงไหม + เข้าบัญชี อบต. ไหม + เคยใช้สลิปนี้แล้วหรือยัง**
4. ✅ ผ่านครบ → ปุ่ม **"ยืนยันรับเงิน"** ถึงจะกดได้
5. ❌ ไม่ผ่าน → ปุ่มล็อกไว้ "รอตรวจสลิปก่อน" กดไม่ได้

> ระบบทำงานที่หน้า **รับชำระเงิน** (`/prapa/cashier`) และ **จดมิเตอร์/รับเงินหน้างาน** (`/prapa/reading`)

## 2. ต้องเตรียมอะไรบ้าง (ภาพรวม)

| สิ่งที่ต้องมี | ได้จากไหน |
|---|---|
| **บัญชีพร้อมเพย์ของ อบต.** (บัญชีรับเงิน) | มีอยู่แล้ว — ตั้งในหน้าเรตช่อง "เลขพร้อมเพย์ปลายทาง" |
| **บัญชีผู้ให้บริการตรวจสลิป** + **โทเคน (Token)** | สมัครกับ EasySlip หรือ Slip2Go (ดูขั้นตอนข้อ 3–4) |
| **ชื่อบัญชีผู้รับเงิน** ตามที่ขึ้นบนสลิป | ดูจากสลิปที่โอนเข้าบัญชี อบต. จริง (สำคัญมาก — ข้อ 6) |

> **ตั้งได้หลายเจ้าพร้อมกัน** (EasySlip + Slip2Go) — เจ้าแรกโควตา/โทเคนหมด ระบบสลับไปเจ้าถัดไปให้อัตโนมัติ ไม่มีสะดุด

---

## 3. สมัคร EasySlip แล้วเอาโทเคน

EasySlip อ่านสลิปได้ทั้ง **เป๋าตัง/ธนาคารทุกเจ้า** (เว็บของเราใช้เจ้านี้เป็นหลัก)

1. เข้า **https://easyslip.com** → กด **สมัคร / Register** (ใช้อีเมลของ อบต. หรืออีเมลกลางของผู้ดูแล)
2. ยืนยันอีเมล แล้วเข้าสู่ระบบไปที่ **Dashboard**
3. หาเมนู **API / API Key / Token / ตั้งค่า API** (ชื่อเมนูอาจต่างกันตามเวอร์ชันเว็บ)
4. กด **สร้าง Token / Generate** แล้ว **คัดลอกโทเคน** เก็บไว้ (เป็นข้อความยาว ๆ)
5. ดู **โควตา (Quota)** ของแพ็กเกจ — แบบฟรีมีจำนวนครั้งจำกัดต่อเดือน การตรวจสลิป 1 ใบ = ใช้ 1 ครั้ง ถ้าจะใช้เยอะให้ซื้อแพ็กเกจเพิ่ม

> 💡 เก็บโทเคนไว้ให้ดี = ความลับ (ใครได้ไปตรวจสลิปกินโควตาเราได้) ถ้าหลุด/สงสัยรั่ว ให้เข้า Dashboard กด **ยกเลิก/สร้างใหม่ (Revoke/Regenerate)**

---

## 4. สมัคร Slip2Go แล้วเอาโทเคน (สำรอง)

ตั้ง Slip2Go ไว้เป็น **เจ้าสำรอง** เผื่อ EasySlip โควตาหมด — ระบบจะสลับมาใช้ให้เอง

1. เข้า **https://slip2go.com** → **สมัคร / Register**
2. เข้าสู่ระบบไปที่ Dashboard: **https://app.slip2go.com** (หน้าร้าน/Shop)
3. หาเมนู **ตั้งค่า API / API Key / Secret Key / Token**
4. **คัดลอก Token / Secret Key** เก็บไว้
5. ดูโควตา/แพ็กเกจเช่นเดียวกับ EasySlip

> **SlipOK** (อีกทางเลือก): ถ้าใช้เจ้านี้ โทเคนต้องกรอกในรูปแบบ `branchId:apiKey` (เอา branch id กับ api key มาคั่นด้วยเครื่องหมาย `:`)

---

## 5. เอาโทเคนมาใส่ในระบบ

1. ล็อกอินเข้า **`/prapa`** (ระบบประปา) ด้วยบัญชีที่มีสิทธิ์ **ตั้งค่า**
2. เมนูซ้าย → **ตั้งค่าระบบ** → แท็บ **"พร้อมเพย์"**
3. เช็กช่องบน ๆ ก่อน:
   - **เลขพร้อมเพย์ปลายทาง** = เบอร์/เลขบัตรพร้อมเพย์บัญชีรับเงินของ อบต.
   - **ชื่อบัญชีผู้รับเงิน (แสดงคู่ QR)** = ชื่อที่จะโชว์ใต้ QR
4. เลื่อนลงหัวข้อ **"ตรวจสลิปอัตโนมัติกับธนาคาร (กันสลิปปลอม)"**
5. ในแถวผู้ให้บริการ:
   - เลือกผู้ให้บริการจาก dropdown → **EasySlip**
   - ช่องรหัส (แบบซ่อน ●●●) → **วางโทเคน** ที่คัดลอกมา
6. อยากเพิ่มเจ้าสำรอง → กด **"+ เพิ่มผู้ให้บริการ"** → เลือก **Slip2Go** → วางโทเคนอีกอัน
   - ลำดับบน = ใช้ก่อน · เจ้าบนโควตาหมด → ตกไปเจ้าล่างอัตโนมัติ
7. กรอกช่อง **"ชื่อบัญชีผู้รับเงิน (ตามที่ขึ้นบนสลิป)"** — **สำคัญมาก ดูข้อ 6**
8. กด **บันทึก**

> โทเคนที่ตั้งไว้แล้วจะโชว์เป็น `•••••••• (ตั้งไว้แล้ว)` — ระบบไม่ส่งโทเคนกลับมาโชว์ (ความลับ) ถ้าจะเปลี่ยนให้พิมพ์ทับอันใหม่ ถ้าไม่แตะ = ใช้อันเดิม

## 6. ⚠️ ตั้ง "ชื่อบัญชีผู้รับเงิน" ให้ถูก (จุดที่คนพลาดบ่อยสุด)

ระบบเช็กว่า "เงินเข้าบัญชี อบต. จริงไหม" ด้วยการเทียบ **ชื่อบัญชีผู้รับ** ที่ขึ้นบนสลิป **ไม่ใช่เบอร์พร้อมเพย์**

**ทำไม:** บนสลิปที่โอนพร้อมเพย์ ช่องผู้รับจะโชว์เป็น **เลขบัญชีธนาคารจริง** (เช่น `xxx-x-x4477-x`) ซึ่งเป็นคนละเลขกับเบอร์พร้อมเพย์ → เทียบด้วยเบอร์จะพลาดเสมอ

**วิธีตั้งให้ถูก:**
1. ให้ใครสักคนโอนเข้าบัญชี อบต. จริง 1 บาท แล้วดูสลิป
2. ดูว่าช่อง "ผู้รับ/เข้าบัญชี" บนสลิปขึ้นชื่อว่าอะไร (เช่น `โชคชัย กัลยา`)
3. เอาชื่อนั้นไปกรอกในช่อง **"ชื่อบัญชีผู้รับเงิน (ตามที่ขึ้นบนสลิป)"**

> ✅ ระบบรองรับสลิปที่ตัดนามสกุลด้วย (เช่นสลิปโชว์แค่ `โชคชัย ก` ก็ยังเทียบกับ `โชคชัย กัลยา` ผ่าน)
> ถ้าเว้นช่องนี้ว่าง = ไม่เทียบบัญชีปลายทาง (ยึดแค่ สลิปจริง + ยอดตรง + ไม่ซ้ำ) — **ไม่แนะนำ** เพราะเปิดช่องให้เอาสลิปโอนเข้าบัญชีอื่นมาหลอกได้

## 7. วิธีใช้งานจริงหน้าเก็บเงิน

**หน้ารับชำระเงิน (`/prapa/cashier`) หรือ จดมิเตอร์ (`/prapa/reading`):**

1. เลือกผู้ใช้น้ำ + บิลที่จะจ่าย
2. เลือกช่องทาง **QR / QR PromptPay**
3. ยื่นจอ/QR ให้ลูกค้าสแกนจ่าย
4. ลูกค้าโอนเสร็จ → ลูกค้าโชว์สลิป → เจ้าหน้าที่กด **"ถ่าย/เลือกรูปสลิป เพื่อตรวจ"** ถ่ายรูปสลิป
5. รอ 2–5 วินาที ระบบตรวจ:
   - ✅ ขึ้น **"ตรวจสลิปผ่าน — ลูกค้าโอนมาแล้ว X บาท"** (สีเขียว) → ปุ่มยืนยันปลดล็อก → กด **ยืนยันรับเงิน**
   - ❌ ขึ้นเหตุผลสีเหลือง (ยอดไม่ตรง/บัญชีไม่ใช่ อบต./สลิปซ้ำ) → ปุ่มยังล็อก แก้ให้ถูกก่อน

> ลูกค้าที่จ่ายเองที่บ้านแล้วแนบสลิปมา → เจ้าหน้าที่ตรวจได้ที่เมนู **"ตรวจสลิปโอน"** (`/prapa/slips`)

## 8. เจอข้อความแบบนี้ หมายความว่า

| ข้อความ | แปลว่า | ทำยังไง |
|---|---|---|
| **ตรวจสลิปผ่าน — โอนมาแล้ว X บาท** | ผ่านหมดทุกเงื่อนไข | กดยืนยันรับเงินได้ |
| **ยอดในสลิปไม่ตรง** | ยอดที่โอน ≠ ยอดบิลที่เลือก | เช็กว่าลูกค้าโอนครบไหม / เลือกบิลถูกไหม |
| **บัญชีปลายทางไม่ใช่ของ อบต.** | ชื่อผู้รับบนสลิปไม่ตรงที่ตั้งไว้ | ไปตั้ง "ชื่อบัญชีผู้รับเงิน" ให้ตรง (ข้อ 6) |
| **สลิปใบนี้ถูกใช้ชำระไปแล้ว (เลขอ้างอิงซ้ำ)** | เอาสลิปเดิมมาใช้ซ้ำ | ต้องใช้สลิปการโอนใบใหม่ |
| **ยังไม่ได้ตั้งผู้ให้บริการตรวจสลิป** | ยังไม่ใส่โทเคน | กลับไปข้อ 5 |
| **เชื่อมต่อบริการตรวจสลิปไม่ได้** | โทเคนผิด / เน็ตล่ม / โควตาหมดทุกเจ้า | เช็กโทเคน + โควตาในเว็บผู้ให้บริการ |

## 9. เรื่องค่าใช้จ่าย / โควตา

- การตรวจสลิป **1 ใบ = ใช้โควตา 1 ครั้ง** ของผู้ให้บริการ
- แพ็กเกจฟรีมีจำนวนจำกัดต่อเดือน — ถ้า อบต. เก็บเงินเยอะ ควรซื้อแพ็กเกจเพิ่ม หรือ**ตั้ง 2 เจ้า**ให้ระบบสลับกันใช้
- ระบบจะไม่ตรวจซ้ำถ้าสลิปเดิม (กันเปลืองโควตา + กันโกง)

## 10. หมายเหตุสำหรับผู้ดูแลระบบ (เชิงเทคนิค)

- โค้ด adapter ผู้ให้บริการ: `backend/src/modules/water/slip-verify.ts` (รองรับ EasySlip / Slip2Go / SlipOK — เพิ่มเจ้าใหม่ได้ที่นี่)
- ตรรกะตรวจ + บันทึกกันซ้ำ: `verifySlipForBills()` / `assertSlipVerify()` ใน `water-billing.service.ts` · ตาราง `water_slip_verify` (UNIQUE `organization_id + trans_ref`)
- ตั้งค่าเก็บที่ `water_rate.slip_verify_providers` (jsonb, โทเคนเป็น secret) + `water_rate.slip_receiver_name`
- โทเคน **ไม่ถูกส่งกลับ frontend** — API คืนแค่รายชื่อผู้ให้บริการที่ตั้งไว้
- แต่ละ อบต. ตั้งของตัวเอง (multi-tenant) — โทเคน/ชื่อบัญชีแยกตาม `organization_id`
